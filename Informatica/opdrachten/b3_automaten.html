Arduino Thermometer

Automaten (B3)

Tijdsindicatie: 1 tot 2 uur | Niveau: 1 | Domein: B3

Inleiding

Met deze opdracht ga je van een Arduino een digitale thermometer maken. Daarvoor ga je Arduino-code schrijven. Dat doe je online via https://app.arduino.cc/.

Benodigdheden

  • Arduino
  • Temperatuursensor
  • Draadjes
  • Krokodillenklemmen
  • Diverse weerstandjes
  • Display

Stappenplan

  1. Tutorial: Zoek online een tutorial op (bijvoorbeeld via Google of YouTube).
  2. Bouwen: Bouw de schakeling.
  3. Coderen: Schrijf de code.
  4. Testen: Test je opstelling.
  5. Onderzoeken: Onderzoek hoe de code werkt.
  6. Uitleg: Schrijf je uitleg over de verschillende onderdelen van de code.
  7. Portfolio: Plaats je code, uitleg en foto’s van de opstelling op de website.

Beoordelingsmodel

Categorie 0 punten 1 punt 2 punten 3 punten 4 punten
Voorbereiding & Schakeling Er is geen schakeling gebouwd of deze is onherkenbaar. Er is een poging gedaan, maar de schakeling is foutief aangesloten en werkt niet. De schakeling is grotendeels correct opgebouwd; kleine fouten zorgen voor storingen. Havo: De schakeling is volledig correct opgebouwd en werkt stabiel.
VWO: Daarnaast kan de leerling uitleggen waarom de componenten op die manier zijn aangesloten (bijv. functie van weerstanden). 		N.v.t.
Code & Werking Er is geen code ingeleverd of de code werkt niet. Er staat code in het project, maar deze werkt slechts deels of foutief. De thermometer leest de temperatuur goed uit, maar niet continu of rommelig. Havo: De thermometer leest nauwkeurig en real-time uit. De leerling kan uitleggen hoe de code werkt.
VWO: Daarnaast bevat de code geen onverklaarbaar complexe constructies en kan de leerling de werking van elke functie toelichten. 		N.v.t.
Uitleg & Reflectie Er is geen uitleg gegeven. Er is een korte en onvolledige uitleg van de code. De belangrijkste onderdelen van de code zijn benoemd en uitgelegd. Havo: Alle onderdelen van de code zijn duidelijk uitgelegd, inclusief reflectie op werking.
VWO: Daarnaast beschrijft de leerling verbeteringen die mogelijk zijn en legt uit hoe de sensor werkt op hardwareniveau. 		De leerling heeft een onverwachte uitbreiding gemaakt, zoals het toevoegen van een display, alarm bij bepaalde temperatuur, of logging naar een bestand.
Let op: Je moet in elke categorie minimaal 1 punt halen. Als je op een onderdeel 0 punten scoort, wordt de opdracht niet nagekeken en moet je deze eerst aanvullen.

Cijfer = (totaal aantal punten / 10) * 9 + 1
