# servaaswinder.nl

Website met lesmateriaal voor Natuurkunde, Fotografie en Technasium, gebouwd met Jekyll en gehost op GitHub Pages.

Informatica staat op [northgo-informatica.nl](https://northgo-informatica.nl).

Lokaal draaien:

```bash
bundle install
bundle exec jekyll serve --livereload   # http://localhost:4000
```
