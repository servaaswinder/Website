# README
Dit is een site voor leerlingen natuurkunde en informatica. Vooral voor informatica wordt hier veel gebruik van gemaakt. Alle odprachten staan er op. Het zit tegen een leerling volgsysteem aan. Docenten kijken na via dit systeem

De site is gemaakt met jekyll en github pages. Alle autenticatie en opslag van gegevens is gemaakt met firebase.

**Features:**
- [x] Tijdstempel bij overzicht gemaakte opdrachten, zowel docentend ashboard als leerling dashboard.
- [x] Bij nakijken van een opdracht op het docentendashboard, moet de titel van de odpracht zichtbaar zijn, niet alleen maar de code van de odpracht. 
- [x] Bij het nakijken van en een opdracht moet duidelijk worden of het de eerste keer is dat deze odpracht is ingeleverd/nagekeken. Als deze opdracht als een eerder is nagekeken moet in de rubric de vakjes aangekruist zijn die als deze waren bij de vorige keer. Mogelijk is een deel hiervan al gemaakt, maar dat is niet niet heel duidelijk. 
- [x] De optie toevoegen om een opdracht te met maximaal een 6. Als een vinkje bij het nakijken. Met de tekst te laat ingeleverd. 
- [x] Bij het nakijkscherm ook de tijdstemper erbij zetten van het inleveren en van eventuele eerder ingeleverde opdrachten. 
- [x] **Mini Logboek**: Volledige geschiedenis van inleveren en nakijken in het leerlingoverzicht (met icoontjes 📬 en ✅).
- [x] Bij de het overzicht van de cijfers is de kolom voor de periode erg breed, terwijl daar maar P1 of P2 enzovoort staat. De kolom voor de opmerkingen kan dus wat breeder.
